# 砺题 Liti

> 千题磨一剑 · 面向局域网的学习刷题系统

**当前版本 v1.0.0**（2026-11-03）—— 里程碑 M1–M15 全部收口，功能冻结，进入维护期。

砺题（Liti）是一款用于**学习与刷题**的在线答题系统，以选择题（单选 / 多选）为主。支持题库管理、Excel 批量导入导出、随机组卷与固定组卷、答题倒计时、防切屏、自动判分与逐题解析，以及**学生自助练习**与**人人独立的错题本**。

数据默认存储于 **SQLite**，预留 **MySQL** 接入；认证支持本地账号，预留 **SSO（OIDC）** 接入。

## ✨ 功能特性

- **首页免登录可看**：题库规模、已发布试卷、卷面预览都在首页；点「开始答题」跳到登录页，登录完自动回到那张卷子并开考。
- **题库管理**：单选 / 多选题目，含题干、选项、正确答案、解析、分类；题干与选项都能配图（也可只放图、不写字）；支持界面逐题录入 + Excel 批量导入（题型列是下拉菜单、表头带批注、附填写说明页），新增/导入时自动和已有题目查重；支持**批量改分类 / 批量删除**。
- **题库导出**：按当前筛选条件（分类 / 状态 / 关键词）导成 xlsx，**列结构与导入模板完全一致** —— 导出来改几笔就能原样回导，做成一份卷子改题的闭环。单次最多 5000 行，文件里另附一页「导出信息」写明筛选条件与截断情况。
- **删除不伤历史**：题目删除是「从题库移除」，已组进试卷的题目在历史试卷、已发布试卷和已交答卷里照常显示题面与解析。
- **灵活组卷**：两种方式随你选 —— 按分类随机抽题（可配多条规则，留空即全题库），或直接从题库里手动多选；每卷 1–100 题，题量可自定义。建卷前可「预览卷面」先看效果，发布后也能随时预览。
- **发布可控可见**：发布时可选「所有学生」或「指定范围」—— 范围既可以是**个别学生**，也可以是**学生分组**（两者取并集）；没被覆盖到的学生看不到这份卷子（连标题都看不到），发布后还能随时改名单。分组挂的是引用不是快照，往里加人立刻生效。
- **学生分组**：教师 / 管理员可以建分组、改名字、批量管成员（一份卷子发给一个班就靠它，不用每次点几十个名字）；成员只收学生账号，删组会连带清掉试卷上的分组授权，不留悬空引用。
- **答题防作弊**：选项 A/B/C/D 顺序每次随机；整卷倒计时；切窗口 / 切标签页 / 关页面都会被记录，回来弹窗提醒，累计 3 次自动交卷；答案自动保存；支持**暂停考试**（停表 + 服务端屏蔽题面）；可给题目**打标记**，答题卡上有小圆点提示。
- **答案不会因为网络抖一下而丢**（v0.10）：作答按题合并后串行保存，断网自动指数退避重试，顶部实时显示「已保存 / 重试中 / N 题未同步」；网络恢复会自己补存，不用刷新页面。万一一直不通，**交卷时会把没落盘的答案一起带上**，照样算分。超时之后带答案提交无效（防止拖到最后一秒补答案）。
- **作答次数按卷配置**（v0.8）：建卷时自己填（1–99），**统考卷填 1 就是「一场只给一次」**，小测填 3、练习卷直接不限。中途退出会接着上次那张卷子，不白占次数。
- **判分与解析**：交卷自动判分；支持「考试模式（交卷后统一显示）」与「练习模式（逐题即时反馈）」两种解析时机；交卷原因中文标注（正常 / 超时 / 违规）。
- **练习中心（学生自助）**：学生自己开练习卷，不用老师建 —— 按分类随机抽题（可多选分类、题量自由、多分类自动平均分配），或**拿自己的错题练一遍**；练习卷即时反馈、不限作答次数，不占考试次数。
- **独立错题本**：答错自动进本，答错一次累加一次次数；**做对一次就移出「待订正」**（记录保留，之后又错会重新拉进来）。错题库按人生成、按人隔离 —— 接口层面就不接受「查谁」这个参数，谁登录看谁的，读别人的错题详情直接 404。支持按状态 / 分类筛选、题干搜索、批量移除，详情里能看正确答案和解析。
- **教师能管学生**：管理员管所有人；教师可以查看、新建、改资料、重置密码、删除**学生**账号 —— 但不能造教师、不能改角色、不能碰管理员、不能删自己。越权判定在服务端，不是前端藏个按钮。
- **正式考试能用了**（v0.7）：建卷时设**开考 / 结束时间**，没到点进不去、到点自动收卷；教师可以随时**强制收卷**（所有还在答题的立刻判分）。考试卷可**禁止学生自行暂停**。**每题分值**自己定，及格判定按**绝对分**走（不再跟着题数漂）。**成绩与解析分开发布** —— 可以先只给分数、考完再放答案，也可以设成永不公布。**成绩册按场次导出**，应考名单为主表、缺考的人照样占一行写「未参加」。有答卷的卷子删不掉，只能**归档**（学生看不到，成绩一直留底）。
- **成建制开学籍**（v0.8）：账号带**学号**（全校唯一，服务端查重）与**班级**。学生名单用一份 Excel 批量导入 —— 下载模板、上传、**先预检看报告**（谁会被创建、谁重名跳过、哪行格式错），确认后才真写库；1000 人的表里有几行错，剩下的人照样进得来（逐行独立提交，不是整批回滚）。导完直接回显统一初始密码。用户管理页可按**班级**筛人、按关键词搜人。
- **成绩册按班级导出**（v0.8）：整场导出时按「班级 → 学号」分块排序，一个班的人挨在一起；也可以只导某个班，文件里附「本次导出班级 / 该场应考总人数 / 本班应考人数」，拿到表的人能判断这份表全不全。
- **逐题分析**（v0.9）：考完能回答「哪道题出坏了」——每题的 **P 值（正确率）**、**D 值（区分度）**、**选项分布**（每个干扰项有多少人踩）、以及整卷的**分数段分布**。D 值是拿总分前 27% 与后 27% 的学生对比出来的：**D 为负会自动标红提示「疑答案有误」**（差学生反而答对更多，通常就是答案标反了），区分度低于 0.2 的题会提示改写或换掉。可只看「需关注」的题、可按班级单独分析、可导出 xlsx（逐题 / 分数分布 / 考试信息三张表）交给教研。
- **实时监考**（v0.11）：考试进行中能看到应考名单上每个人此刻的状态——未开始 / 答题中 / 已暂停 / 已交卷 / 已超时，外加**掉线**标记。学生答题页每 20 秒发一次心跳，90 秒没收到就标掉线（**掉线不等于作弊**，多半是网络断了）。列表实时显示已答题数、剩余时间、违规次数，每 10 秒自动刷新，可按状态、班级筛，可按姓名/学号搜。**违规可以撤销**：误判的切屏（按 F5、输入法弹窗、系统弹窗抢焦点）点一下就撤，撤销后学生重新获得一次额度，记录仍保留并可恢复。另外，学生被强制收卷时页面会**自己发现并跳转**，不用等他再点一次才发现卷子早交了。
- **审计日志**（v0.12）：回答「这件事是谁干的」—— 发布 / 归档 / 删卷 / 强制收卷、改账号 / 重置密码 / 删账号、导入导出题库、建删分组、改站点设置、撤销违规、登录与登录失败，**42 个动作**全部留痕。每条记录带**操作人与对象名称的快照** —— 账号后来改名甚至被删了，日志里仍是当时那个名字。可按类别、动作、分级（日常 / 敏感 / 高危）、操作人、对象、关键字、时间范围筛，可导出 CSV 留档。**只有管理员能看**；清理旧日志是高危操作，而且「谁清过日志」这条永远删不掉。学生答题流水不进这里 —— 答卷表自己带时间戳，几十万条答题记录只会把要查的几条埋掉。
- **题序乱序**（v0.13）：和「选项乱序」一起构成 A/B 卷 —— 选项乱序让每个人的 ABCD 位置不同，题序乱序连**题目顺序**都每人一份，对暗号「第 3 题选 B」就不成立了。顺序在**开考那一刻定下并落库**，刷新、续答、换设备都不会变；判分只认题目 ID，逐题分析仍按出题顺序统计。**默认关闭**：开了之后「第 3 题」在师生之间指代的不是同一道题，讲评要按题目说不按序号说，这个代价得老师知情后自己选。
- **找回密码**（v0.14）：忘了密码不用等管理员进后台 —— 老师 / 管理员在用户管理页一键签发 **8 位一次性重置码**（自动去掉 0/O/1/I/L 这类抄不清的字形），念给学生或写在纸上，学生在登录页「忘记密码？」弹窗里 30 分钟内自助改密。库里只存哈希、明文只显示一次、用过即作废、重发自动作废旧码；兑换接口公开但有双维度限流，失败一律同一句话术，不透露用户名存不存在。改密成功后所有已登录会话即刻失效。
- **运维有据可依**（v1.0）：仓库带 `scripts/liti-backup.sh` —— SQLite 走 `.backup` 在线热备（直接拷 `app.db` 会漏掉 WAL 里的新数据）、MySQL 走 `mysqldump --single-transaction`，备份完立刻做完整性校验并打出各表行数。恢复步骤写在 [docs/deployment.md](docs/deployment.md) 第 13 节，**真停机换文件恢复**已验证：恢复后健康检查、管理员登录、六表行数全部一致。压测脚本 `scripts/liti-bench.mjs` 覆盖登录 / 题库列表 / 答题自动保存 / 完整考试流等六个场景，2 核 2G 机器上的基线数据在同文档第 14 节 —— 瓶颈不在接口层。
- **站内帮助**：`/help` 一份完整使用说明，未登录也能看。
- **安全**：会话 token 32 字节随机、库里只存哈希、Cookie `HttpOnly` + `SameSite`；登录失败双维度限流（用户名+IP、单 IP）；停用账号 / 改密码即刻踢下所有会话；权限判定全在服务端（学生越权 403、名单外试卷一律 404）；考试模式答题中不下发答案与解析，暂停时题面在服务端就抹掉。详见 [docs/security.md](docs/security.md)。
- **双数据库**：默认 SQLite（零配置本地运行），通过配置切换 MySQL，数据访问层统一。
- **可扩展认证**：本地账号 + 角色权限（管理员 / 教师 / 学生）；预留 SSO（OIDC）接入点。

## 🚀 快速开始

### 环境要求

- Node.js ≥ 20（推荐 22）
- pnpm ≥ 8

### 本地开发

```bash
# 1. 安装依赖
pnpm install

# 2. 启动后端（默认 http://localhost:8080，SQLite）
pnpm dev:server

# 3. 启动前端（Vite 开发服务器，代理到后端）
pnpm dev:web
```

### 生产部署（局域网）

```bash
pnpm build          # 构建后端 + 前端
pnpm seed           # 建库 + 初始账号
pnpm start          # 单进程运行，托管 API + 静态资源
```

浏览器访问 `http://<局域网IP>:8080`。完整部署步骤（防火墙、开机自启、MySQL、Electron 等）见 [docs/deployment.md](docs/deployment.md)。

### 演示站（给人试用）

想挂一个公网 demo 让人直接点，不用发账号密码：

```bash
cd deploy/demo
cp .env.example .env      # 填 SESSION_SECRET
docker compose up -d
```

镜像和正式版是同一个，靠 `DEMO_MODE=1` 打开三个东西：登录页的「一键体验」（免密进管理员/教师/学生）、全站顶部的演示横幅、每小时自动还原的演示数据。数据是一整套用了一学期的现场——40 道题、4 张试卷、24 个学生、19 份已出分的答卷，监考页里还有人正在作答。

完整部署手册（空机器到域名 + HTTPS，含排错与安全红线）见 [deploy/demo/DEPLOY.md](deploy/demo/DEPLOY.md)，简版见 [deploy/demo/README.md](deploy/demo/README.md)。

域名已经被别的站点占着？填 `BASE_PATH=/liti/` 就能挂在 `https://已有域名/liti/` 下，不用另外申请域名。nginx 配置见 [deploy/demo/nginx-subpath.conf.example](deploy/demo/nginx-subpath.conf.example)，步骤见 DEPLOY.md 第 8.7 节。

数据存在 SQLite 里，单文件落在 Docker 命名卷，不用另装数据库。

> 这个开关等于把登录门拆了，**只能开在演示实例上**。正式部署别抄那份 compose。

## ⚙️ 配置

通过环境变量或 `.env` 文件配置（模板见 `server/.env.example`）：

| 变量 | 说明 | 默认 |
|---|---|---|
| `HOST` | 监听地址 | `0.0.0.0` |
| `PORT` | 端口 | `8080` |
| `DB_DRIVER` | `sqlite` 或 `mysql` | `sqlite` |
| `SQLITE_PATH` | SQLite 文件路径 | `data/app.db` |
| `MYSQL_URL` | MySQL 连接串（`DB_DRIVER=mysql` 时） | — |
| `SESSION_SECRET` | 会话密钥 | 随机 |
| `AUTH_PROVIDERS` | `local` / `local,oidc` | `local` |

### 切换 MySQL

```bash
DB_DRIVER=mysql MYSQL_URL="mysql://user:pass@127.0.0.1:3306/liti" pnpm start
```

### 接入 SSO（OIDC）

配置 `OIDC_ISSUER` / `OIDC_CLIENT_ID` / `OIDC_CLIENT_SECRET` / `OIDC_REDIRECT_URI`，并将 `AUTH_PROVIDERS` 设为 `local,oidc`（或 `oidc` 强制 SSO）。详见 [docs/architecture.md](docs/architecture.md)。

### 桌面壳（Electron）

```bash
pnpm build                         # 构建前端
pnpm --filter @liti/server build   # 构建后端 dist（Electron 依赖它）
pnpm electron:build                # 编译 Electron 主进程 / 预加载脚本
pnpm electron:start                # 启动桌面应用（需 node 在 PATH，或设置 LITI_NODE）
```

Electron 壳在考试期间启用**物理级防切屏**：全屏 + 置顶 + 失焦自动拉回；违规仍由服务端累计，满 3 次自动交卷。浏览器环境则退化为「遮罩 + 检测 + 惩罚」。
