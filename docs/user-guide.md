# 使用手册

写给真正要用它上课的人。按角色分三部分，老师那部分最长——因为它是主力用户。

站内还有一个 `/help` 页面，内容更细，随时能翻。这份文档更适合打印出来给新老师看。

---

# 一、老师

## 1. 第一次用，先做这四件事

1. 登录，点右上角头像 →「个人设置」把密码改掉（`admin` / `admin123` 只是初始账号）。
2. 进「分类管理」，建几个分类，比如「第一章 集合」「第二章 函数」。分类是后面随机抽题的依据，建议按章节分。
3. 进「题库」，把题目录进去，或者用 Excel 批量导入。
4. 进「用户管理」，把学生账号建好，或者用 Excel 导入名单。

这四件做完，就能组卷考试了。

## 2. 录题

**单题录入**：点右上角「新建题目」，选题型（单选 / 多选 / 判断），填题干、选项、正确答案、解析、分类。

题干和选项都可以配图。点配图按钮上传，图片限 12MB，支持常见格式。

**解析**要写。学生在交卷后能看到它，这是这套系统比纸质卷强的地方之一——错在哪，当场就知道。

**重复题会被拦住**。系统按题干内容算哈希，导入或保存时发现重复会弹窗问你「确定要加吗」。同一道题在两个班都要用的话，就一道题配多个分类，别建两份。

**删题不会伤到历史卷**。删掉的题变成「归档」，已考过的卷子里照样能看、能复盘，只是新卷子抽不到它了。

## 3. Excel 批量导入

点「模板」下载的 xlsx 有 12 列：

| 列 | 说明 |
|---|---|
| 题型 | 单选 / 多选，模板里有下拉 |
| 题干 | 纯文本，要配图的话先导入再从界面补 |
| 选项 A–F | 判断题只填 A、B |
| 正确答案 | 单选填一个字母，多选填多个（如 `AC`） |
| 解析 | 可以留空，但不建议 |
| 分类 | 填分类名，不存在会自动建 |
| 标签 | 逗号分隔 |

填完上传，系统先预检一遍再问你确认。预检不写库，看到一堆错误可以直接改表重传。真正导入时是**逐行独立提交**的：第 20 行错了，前 19 行照样进，报告里告诉你第 20 行为什么错。

导出的文件和模板列一致，**改完能直接再导回去**。所以批量改题最简单的办法是：导出 → Excel 里改 → 导入。

## 4. 组卷

试卷页点右上角「新建试卷」，两种模式：

**固定题目**：从题库里勾选具体题目。适合单元测验，题目是你指定的。

**随机抽题**：给规则，比如「第一章抽 10 道、第二章抽 5 道」，系统从对应分类里随机抽。适合期末复习卷，每次抽出来的不一样。

两种都可以先「预览」，看一遍卷子长什么样再保存。预览是草稿，不占试卷数。

几个关键设置，想清楚再填：

| 设置 | 怎么填 |
|---|---|
| 时长 | 分钟。到点自动交卷 |
| 每题分值 | 不填就按总分平均分 |
| 及格分 | 按绝对分判，不是百分比。学生自助练习的卷子不走这里，默认按满分 60% 自动判 |
| 作答次数 | 考试填 1；练习卷填 99 表示不限 |
| 选项乱序 | 建议开。每个人的 ABCD 位置不同，对答案没用 |
| 题序乱序 | **想清楚再开**，见下 |
| 考试时间窗口 | 填了之后，没到点不能开考，到点自动收卷 |

**题序乱序的代价**：开了之后每个人拿到的题目顺序不一样，这能防「第 3 题选 B」这种暗号。但代价是——你讲评的时候不能说「第 3 题」，因为学生眼里的第 3 题可能是别人的第 7 题。得按题目内容说。所以默认是关的，你自己权衡。

## 5. 发布与可见范围

卷子建好是草稿，学生看不见。点「发布」之后才可见。

发布时能设可见范围：

- **全部学生**：所有学生账号都能看到
- **指定分组**：只有组里的学生能看到
- **指定学生**：手动勾

分组在「学生分组」页管理，加人立即生效，不用重新发布。

## 6. 考试当天怎么组织

这是最容易出岔子的一环，按顺序来：

**考前 10 分钟**

1. 确认试卷已发布，时间窗口覆盖今天的考试时段。
2. 在试卷列表里找到这场考试，点行尾「更多」→「实时监考」，看应考名单对不对（缺人的话去分组里加）。
3. 让学生打开浏览器，输入地址，登录。

**开考**

4. 学生自己点「开始答题」。你不用一个个开。
5. 盯「实时监考」页。这里能看到每个人：在线还是掉线、答了几题、剩多少时间、违规几次，每 10 秒自动刷新。

**中途**

- 有人掉线：先别慌。90 秒没心跳才算掉线，网络抖一下很常见，恢复后答案会自动补交。
- 有人违规（切屏）：系统会计数，到 3 次自动交卷。如果是误报（比如输入法弹窗），在监考页找到那条记录点「撤销」，额度会退回来。
- 有人卡住：让他刷新页面，答案在服务端，不会丢。

**收卷**

6. 时间到会自动收。想提前收就点「统一收卷」，所有在考的答卷立刻强制提交。
7. 收完点「发布成绩」，学生才能看到分数。解析可以单独再发一次——想先讲卷再给解析，就分开点。

**考后**

8. 看成绩：试卷行「更多」→「导出成绩（含缺考）」，导出 xlsx。没参加的人照样占一行写「未参加」。只要某个班就点「按班级导出成绩」。
9. 看题目质量：「更多」→「逐题分析」。哪道题错得多（P 值低）、哪道题区分度好（D 值高），讲评前看这个比凭感觉准。分析结果也能导成 xlsx，三张表。

## 7. 成绩怎么读

**P 值**（难度）：这道题的得分率。0.8 表示 80% 的人答对了，简单；0.3 表示只有 30% 对，难。一般认为 0.3–0.7 比较合适。

**D 值**（区分度）：高分组的得分率减分组的得分率。高于 0.4 是好题，0.2 以下要考虑改。**少于 8 个人考的时候不显示**，人太少算出来是噪音。

**未公布成绩时，分数是空白不是 0。** 看到空白就是还没发布，别以为是学生考了 0 分。

## 8. 练习和错题

「练习中心」给学生自助用，你可以不参与。学生可以：

- 随机抽题练（按分类）
- 从自己的错题里抽题练

错题本是自动的：答错就进，答对同一道题就出。每个学生只能看自己的，接口层面就没有查别人错题的入口。

# 二、学生

## 答题

登录后在首页或「试卷」页找到老师发的卷，点「开始答题」。

答题页左边是题目，右边是答题卡。几个操作：

- **选答案**：点选项。答案会自动保存，不用手动点保存
- **标记**：拿不准的题点一下标记，答题卡上会出现黄点，方便回头再看
- **跳题**：点答题卡上的题号
- **交卷**：点「交卷」，确认后不能再改

## 几个常见情况

**网断了怎么办？**
答案存在本地，网络恢复后会自动提交。页面顶部的保存状态会显示「重试中 / N 题未同步」，恢复后自己变成「已保存」。断网期间可以继续答，别关页面。

**不小心切到别的窗口会怎样？**
会被记一次违规，屏幕被遮罩，点「返回考试」继续。累计 3 次会自动交卷。所以考试时把微信、QQ 都关掉。

**页面崩了 / 电脑重启了？**
重新登录，进「我的答卷」，找到那张进行中的卷点「继续」。答案都在服务端，重新开考也是接着答。

**能看到分数吗？**
老师发布了才能看。没发布的时候成绩页是空的。

**错题本在哪？**
左侧菜单「错题本」。答错的题自动进去，答对同题自动出来。也可以手动移出。

# 三、管理员

## 账号

三种角色：管理员、教师、学生。管理员能管所有人，教师只能管学生——教师的菜单里这一项叫「学生管理」，管理员看到的是「用户管理」，是同一个页面。

**批量建学生**：进「用户管理」，点「导入学生名单」，弹窗里先下载模板。填好学号、姓名、班级后上传，系统会先预检再问你要不要真导入。导入完回显统一初始密码，你导出给学生就行。学号重复的那行会跳过，其他行照常进。

**学生忘了密码**：在用户管理页找到这个人，点「生成重置码」，系统给一个 8 位码（比如 `C325YZRN`）。

**这个码只显示一次**，关掉窗口就没了。抄给学生，让他自己在登录页点「忘记密码？」输入。码 30 分钟内有效，用一次就失效。

学生自己也可以在登录页点「忘记密码？」，但需要先有码——码只能由老师或管理员发。

## 系统设置

站点名称、公告这些在「网站管理」页改（只有管理员有这个菜单）。公告会显示在首页，用来通知「下周三考试」这类事。

## 审计日志

「审计日志」页能看到所有管理动作：谁发布了哪张卷、谁删了哪个账号、谁改了哪个学生的密码、谁登录失败了。

三个用法：

- **查某个人干了什么**：按操作人筛
- **查某张卷经历了什么**：按对象筛
- **查某段时间的异常**：按时间段 + 严重级筛，`critical` 那档是删账号、强制收卷这类

日志里的名字是当时的快照。就算账号后来改名或删了，记录里还是原来的名字，不会变成一串 ID。

导出 CSV 可以直接用 Excel 打开（带 BOM，中文不乱码）。

这个页面只有管理员能进。教师和学生看不到入口，直接调接口也是 403。

## 备份

**必须做**，而且必须演练过一次恢复。

```bash
sh scripts/liti-backup.sh
```

SQLite 和 MySQL 都支持。备份文件里是全部数据，包括密码哈希，别乱放。

# 常见问题

**Q：学生说看不到试卷。**
三种可能：卷还是草稿没发布；发布时间窗口没到；这个学生不在可见范围里。按这个顺序查。

**Q：导出的成绩表里有人是空的。**
空是「没参加」，不是 0 分。系统把应考名单和答卷做了左连接，没答卷的留空。

**Q：分析页的 D 值是空的。**
这场考试实考人数少于 8 人。人太少算区分度没意义，所以不给。

**Q：教师账号改不了另一个教师。**
设计如此。教师只能管学生，跨教师操作服务端会拒绝。

**Q：能一次导出所有场次的成绩吗？**
不能，成绩按场次导出（每张卷一个文件）。想汇总多场，导出多个文件在 Excel 里合并。要跨场看答卷流水，用「我的答卷」页的导出。

**Q：能不能不显示排名？**
导出的成绩表是明细，没有排名列。要排名自己在 Excel 里排。

**Q：手机能用吗？**
能打开、能看，但答题体验不好。考试请用电脑。
